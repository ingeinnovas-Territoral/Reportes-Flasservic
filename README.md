# App Reportes – Flassservic S.A.S.

App para hacer reportes de mantenimiento en el celular. Funciona **sin internet**.

## 1. Dirección de la app

https://ingeinnovas-territoral.github.io/Reportes-Flasservic/

## (Alternativa) Publicarla en Netlify

La app necesita una dirección web para instalarse en el celular. Solo hace falta internet para este paso y para la primera apertura. Después funciona sin señal.

**Opción fácil (Netlify, gratis):**
1. Descomprima el archivo `reportes-flassservic.zip`. Le queda la carpeta `reportes`.
2. Entre a **app.netlify.com/drop** y cree una cuenta gratis (puede entrar con Google).
3. Arrastre la carpeta `reportes` a la página.
4. Netlify le da una dirección del tipo `https://algo.netlify.app`. Puede cambiarle el nombre en *Site configuration → Change site name*, por ejemplo `reportes-flassservic.netlify.app`.

## 2. Instalarla en el celular de Héctor

1. Abra la dirección en el celular (**Chrome** en Android, **Safari** en iPhone) con internet.
2. Instálela:
   - **Android:** menú ⋮ → *Agregar a pantalla principal* → *Instalar*.
   - **iPhone:** botón Compartir → *Agregar a pantalla de inicio*.
3. Queda el ícono **Reportes**. Ábrala una vez con internet y desde ahí funciona sin señal.

**Ingreso inicial:** usuario `Hector`, contraseña `1234`. En **Ajustes** cambie la contraseña, ponga la cédula y guarde la firma una sola vez: después sale sola en cada reporte.

## 3. Uso diario

- **Sedes:** toque *Hospital* o *Comité* de una sede, luego **+ Nuevo reporte**.
- El reporte se **guarda solo** mientras se llena. El número es consecutivo y automático.
- **Fotos:** use *Foto antes* y *Foto después*. Salen en una segunda hoja del PDF.
- **Firmas:** la del técnico (Héctor) sale sola. La del cliente se toma con el dedo en el recuadro.
- **Generar PDF:** compártalo directo por WhatsApp o correo, o descárguelo.
- **Equipos:** cada equipo queda registrado con su historial de servicios (hoja de vida).
- **Estados:** Pendiente, En proceso o Terminado. En el inicio se ven los totales.

## 4. Respaldo (importante)

Los datos se guardan **solo en ese celular**. Una vez por semana entre a **Ajustes → Descargar copia de respaldo** y guarde el archivo en Drive o envíelo por WhatsApp. Si cambia de celular o se borra el navegador, use **Restaurar copia**.

## 5. Actualizar la app

Si se le hacen cambios, arrastre la carpeta nueva al mismo sitio de Netlify (*Deploys → arrastrar carpeta*). Los datos del celular no se pierden.
